| 数据源 | 地址 | 可达性 | 说明 |
|---|---|---|---|
| NOAA Coral Reef Watch | https://coralreefwatch.noaa.gov | ⚠️ **间歇可达** | 实测某时段成功下载真实数据，另一时段 TCP 连接超时（DNS 正常）。**必须离线缓存** |

### NOAA ERDDAP 数据集规格（实测确认）

| 项 | 值 |
|---|---|
| 数据集 ID | `NOAA_DHW`（另有 `NOAA_DHW_monthly`、`_Lon0360` 版本） |
| 时间覆盖 | **1985-04-01 → 近实时**（每日更新） |
| 分辨率 | 0.05°（5 km），lat 3600 点，**latitude 为降序** |
| 变量 | `CRW_SST` `CRW_SSTANOMALY` `CRW_HOTSPOT` `CRW_DHW` `CRW_BAA` `CRW_BAA_7D_MAX` `CRW_SST_MAX` `CRW_SSTANOMALY_MAX` + 对应 mask |
| 许可 | 美国联邦政府作品（公有领域） |

```bash
# 仙本那区域（约 4.0–5.0°N, 118.0–119.5°E）日序列
https://coastwatch.pfeg.noaa.gov/erddap/griddap/NOAA_DHW.csv?CRW_DHW,CRW_HOTSPOT,CRW_SSTANOMALY,CRW_BAA[(1985-04-01):1:(2026-10-06)][(5.0):1:(4.0)][(118.0):1:(119.5)]
```

**实测抽样**（2024-08-01，仙本那外海）：

```
time,latitude,longitude,CRW_DHW
2024-08-01T12:00:00Z,4.625,118.525,5.69
2024-08-01T12:00:00Z,4.575,118.525,5.89
```

→ 卫星热压力 **DHW ≈ 4.8 – 5.9 °C-weeks**，已超过 CRW 判定「显著白化」的 4 °C-weeks 阈值。

### 2.3 ⚠️ 关于「14%」这个数字的核验结论

项目简介中「2024 年该区域珊瑚平均白化比例达到 14%」**未能在权威来源中找到支撑**：

| 可核验的数字 | 来源 | 与 14% 的关系 |
|---|---|---|
| 全国平均白化 **50.7%** | 上述报告摘要 | ✗ 不符 |
| 全国平均死亡 **34.1%** | 上述报告摘要 | ✗ 不符 |
| 仙本那周边 4 站位平均白化 **≈32%** | 上述报告 Table 1 | ✗ 不符 |
| 仙本那周边 4 站位平均死亡 **≈11%** | 上述报告 Table 1 | 最接近但仍不符 |
| 「2009–2018 全球珊瑚礁损失约 **14%**」 | *Status of Coral Reefs of the World, 2020*（被同一年报引用） | 疑为**误引** |

**建议**：将表述改为有明确出处的数字，例如
- 「2024 年马来西亚全国平均珊瑚白化率达 **50.7%**，平均死亡率 **34.1%**」
- 「仙本那海域 Larapan 岛 Point 3 站位白化率高达 **69.2%**（DHW 9.4 °C-weeks）」

## 三、⭐ 星地交叉验证（项目最有说服力的一条证据链）

| 数据来源 | 类型 | 仙本那海域 DHW |
|---|---|---|
| NOAA CRW 5km 卫星 | 遥感 | **4.8 – 5.9** °C-weeks（2024-08-01 抽样） |
| Reef Check Malaysia 实地 | 现场测量 | Mabul **6.5**，Larapan **9.4** °C-weeks |

**结论**：卫星热压力与实地热压力处于同一量级，且**两者的空间/站位差异方向一致**
（Larapan 热压力高于 Mabul，实地白化率同样是 Larapan 69.2% 远高于 Mabul 27%）。
这构成一条完整的 **「卫星热压力 → 实地白化」验证链**，可直接用于项目报告。

## 五、对项目落地的直接影响

1. **NOAA 访问必须做离线缓存**：该站点在国内访问间歇性不通。建议一次性拉取
   1985–2025 全时段数据落地为本地文件（CSV/NetCDF），Skill 运行时读本地缓存，
   并保留定时增量更新与失败重试。
2. **Reef Check Malaysia 报告可作为「实地调查数据」的权威引用**（有 Zenodo DOI），
   支撑项目"结合实地采集的珊瑚监测样例数据"这一表述。
3. **验证站点建议固定为 4 个**：Larapan Point 3 / Larapan SMEE 2 / Mabul Eel Garden /
   Mabul Panglima —— 有 DHW、白化率、死亡率三重实测值，可直接做"情景回测"。
4. **14% 需修正**，否则会被质疑数据来源。
