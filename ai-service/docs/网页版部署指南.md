# 网页版（H5）部署指南

> 目标：**不用微信开发者工具**，用浏览器（手机或电脑）打开一个链接就能使用完整服务
> —— 上传照片 → 覆盖率 / 白化 / 珊瑚属 / 个体计数 → 环境热压力 → 投放建议 → 中英文报告。
>
> **整个小程序 23 个页面全部可在网页端使用**（不只是 AI 识别页）。
> 网页版与小程序**调用同一套后端接口、同一批模型**，所以结果完全一致。

---

> **不演示时请关掉服务**（双击根目录 `停止服务.bat`）：本服务默认监听 `0.0.0.0`，同网段设备可能访问到它；关掉就彻底没有这个面。

## 一、它是什么（30 秒看懂）

```
浏览器（手机/电脑）
      │  HTTP/HTTPS
      ▼
serve_fusion.py  （一个进程同时干两件事）
      ├── 网页界面
      │     ├── /                    完整小程序：23 个页面（首页/认养/科普/AI识别/我的 + 全部子页）
      │     └── /lite.html           轻量版：只有 AI 识别一个页面（推荐低配设备用）
      └── AI 接口：POST /analyze、GET /climate、POST /priority …
```

**不需要 Node、不需要打包、不需要额外的 Web 服务器**：FastAPI 自己就把网页托管了。

### 23 个页面是怎么跑起来的

小程序的页面用的是 `Page({...})` + WXML/WXSS，浏览器不能直接跑。本项目**没有改写小程序源码**，
而是在网页端实现了一个**小程序运行时** `web/mp.js`（约 34 KB）：

| 运行时负责 | 做法 |
|---|---|
| `wx.*` 接口（30 个）| 映射到浏览器能力：导航→哈希路由、存储→localStorage、`wx.request`→fetch、`wx.uploadFile`→FormData、`wx.chooseMedia`→文件选择、`wx.getLocation`→geolocation |
| `Page()` / `App()` / `getApp()` | 提供 `data`、`setData`（含 `a.b[0].c` 路径写法）、`onLoad/onShow/onReady/onUnload`、事件派发 |
| `require('../../utils/x.js')` | 自带的 CommonJS 加载器，**utils 源码原样复用**（`api.js`/`mock.js`/`util.js`…）|
| WXML 模板 | 构建期解析成 JSON 树（`tools/build_web_pages.py`），运行期求值渲染（`{{表达式}}`、`wx:if/elif/else`、`wx:for`）|
| WXSS 样式 | 构建期转 CSS：`rpx → calc(N * var(--rpx))`（750rpx = 一个手机宽度，桌面按 480px 封顶）|

**改了小程序页面后**，在 `ai-service/` 下执行一次即可同步到网页版：

```powershell
python tools/build_web_pages.py            # 重建网页产物（默认输出到 web/mp）
python tools/build_web_pages.py --out D:\tmp\mp   # 也可以输出到别处（做一致性比对）
```

> ⚠️ **图片本地化不会丢**：`web/mp/assets/img/` 里的 14 张配图由
> `tools/localize_images.py` 一次性下载（需联网），映射表固化在 `tools/image_map.json`；
> 构建器每次都会自动套用该映射，所以重建后图片仍指向本地文件（否则会变回外部 CDN）。
> 新增图片时的顺序：`python tools/localize_images.py`（下载+写映射）→ `python tools/build_web_pages.py`。
> 验证方式：连续跑两次构建后 `git status` 应为空（说明产物与源码同步、可复现）。

## 二、本机用（1 分钟）

```powershell
cd <项目根目录>\ai-service\scripts
python serve_fusion.py --host 0.0.0.0 --port 8000
```

| 打开地址 | 内容 |
|---|---|
| **http://127.0.0.1:8000/** | **完整小程序 23 页**（电脑浏览器）|
| http://127.0.0.1:8000/lite.html | 轻量版（只做 AI 识别，页面更简单）|
| **http://<电脑局域网IP>:8000/** | **同一 Wi-Fi 的手机**打开，同样是完整 23 页 |

> 首次启动要加载 4 个模型，等 40–90 秒。
> 也可双击仓库里的 `启动网页版.bat`（自动启动并打开浏览器）。

**查自己的局域网 IP**：

```powershell
Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -notlike '127.*' -and $_.IPAddress -notlike '169.254.*' } | Select IPAddress, InterfaceAlias
```

**手机连不上时**（99% 是防火墙）：以管理员身份运行一次

```powershell
New-NetFirewallRule -DisplayName "珊瑚卫士 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow
```

## 三、手机上的功能限制（**必须知道**）

浏览器有"安全上下文"限制，HTTP 与 HTTPS 能用的功能不同：

| 功能 | HTTP（局域网）| HTTPS（公网）|
|---|---|---|
| 上传相册照片 | ✅ | ✅ |
| 拍照（`capture` 唤起相机）| ✅ 多数手机可用 | ✅ |
| **定位（"用我的位置"）** | ❌ 手机浏览器禁用 | ✅ |
| 电脑端全部功能 | ✅ | ✅ |

→ 手机端要**完整功能（含定位）**，就需要 HTTPS（见第四节）。没有 HTTPS 时，用手动选点位即可，不影响识别结果。

## 四、给公网访问（一个真正的"链接"）

> ⚠️ **公开部署前必读：这个服务会跑 4 个模型（吃 GPU/CPU），暴露出去就等于把算力借给别人。**
>
> **默认已经做的防护（不设任何环境变量也生效）**：
> | 行为 | 默认策略 |
> |---|---|
> | 读接口（`/health`、`/corals`、网页资源）| 开放（演示要用）|
> | **写接口**（`POST /corals/import`、`/corals/seed`）| **仅允许本机**，同网段其它设备一律 403 |
> | 推理接口（`/analyze`、`/count`、`/priority`）| 可用，但**每 IP 每分钟 60 次**限流 |
> | 跨域 CORS | 只放行本机与局域网来源，公网域名一律不放行 |
> | 启动提示 | 监听非本机地址时，控制台打印暴露面警告与两种收紧方式 |
>
> **为什么强调**：Windows 防火墙里 `python.exe` 通常已被放行入站（含 Public），
> 而校园网/公共 Wi-Fi 属于 Public 类别 —— 也就是**同 Wi-Fi 的其它设备可能直接访问 8000 端口**。
> 另外 VPN 网卡（Private）也会把端口暴露给 VPN 网段。

## 五、与小程序的关系

| 问题 | 答案 |
|---|---|
| 网页版会不会影响小程序？ | **不会**。网页是**新增**的静态目录 + 根路径挂载，`/analyze` 等接口行为完全未变（有回归验证：23/23）|
| 两边结果一致吗？ | **完全一致**：同一个后端、同一批模型权重 |
| 小程序还需要吗？ | 需要（微信内分享、扫码即用）；网页版解决"没有微信/不想装工具也能用"|

> 小程序真机/上线还要多做一步：在微信公众平台登记
> `request`、`uploadFile`、`downloadFile` 合法域名，并把
> `miniprogram/utils/config.js` 的 `PUBLIC_API_BASE` 改成这个 HTTPS 地址。
> 完整清单见 [`miniprogram/docs/真机与上线部署.md`](../../miniprogram/docs/真机与上线部署.md)。

**网页端对小程序专有能力做了等价替换（如实说明）**：

| 小程序能力 | 网页端行为 |
|---|---|
| 微信登录 | 生成一个本地标识（后端不校验），登录页正常可用 |
| **微信支付**（认养 / 捐赠付款）| **明确提示"网页版不支持微信支付"**，不假装成功（避免误导）|
| 保存证书到相册 | 改用浏览器下载（canvas → PNG）|
| 定位 | 浏览器定位（**HTTP 下手机浏览器会禁用 → 用预设点位**）|
| 分享给好友 | 用浏览器自身的分享 / 复制链接 |

## 七、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 打开 `http://127.0.0.1:8000/` 显示 404 | `web/` 目录丢了 | 确认 `ai-service/web/index.html` 存在（仓库里有）|
| 手机打不开局域网地址 | 防火墙 / 不在同一 Wi-Fi | 见第二节的防火墙命令；确认手机连的是同一个路由器 |
| 页面上点"用我的位置"没反应 | HTTP 下手机浏览器禁用定位 | 用预设点位，或部署 HTTPS（第四节）|
| 上传大照片报 413（公网）| Nginx 默认限制 1 MB | 加 `client_max_body_size 20m`（见 B2）|
| 照片分析很慢（5–10 秒）| 服务器无 GPU，CPU 推理 | 正常；有 NVIDIA 显卡的机器装 CUDA 版 torch 后可到 <1 秒 |
| 环境卡片显示"无数据" | 坐标在网格外，或漏放 `data/noaa/` | 选预设点位；确认 `data/noaa/*.json` 已放好 |

## 八、一句话总结

- **本机 / 局域网**：`python serve_fusion.py --host 0.0.0.0 --port 8000` → 手机电脑都能开
- **要一个公网链接**：先用 Cloudflare Tunnel（10 分钟、自带 HTTPS），长期上线再上"云服务器 + 域名 + nginx + certbot"
- **手机要定位功能**：必须 HTTPS；只要识别结果，HTTP 就够
