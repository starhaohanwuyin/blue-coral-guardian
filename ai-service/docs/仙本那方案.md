# 仙本那珊瑚识别 · 可行性重新评估与修正方案

> 目标锁定：**只在仙本那完成珊瑚识别与白化判断**。
> 本文档取代此前基于加勒比数据的一切结论。

---

## 一、原方案的致命缺陷（自我修正）

| # | 原方案 | 问题 | 后果 |
|---|---|---|---|
| 1 | 用 `tdros/corals` 训练 30 类种级模型 | 该数据集 **10 个类为加勒比特有种**（Acropora palmata/cervicornis、Colpophyllia natans、Diploria strigosa、Meandrina meandrites、Dendrogyra cylindrus、Siderastrea siderea、Montastraea cavernosa、Millepora alcicornis、Diadema antillarum），仙本那**不存在这些种** | 🔴 **模型对仙本那基本不可用**；85.71% 这个数字对目标场景无意义 |
| 2 | 随机划分 train/val/test | 同分布划分，**测不出跨地点泛化** | 🔴 指标虚高，无法回答"在仙本那准不准" |
| 3 | 单次划分报单点精度 | 553 测试样本 / 30 类 ≈ 18 张/类 | 🟡 95% 置信区间约 ±3%，数字不可靠 |
| 4 | MD5 去重即认为数据干净 | 发现 28 张**跨类别重复** → 标注本身有错 | 🟡 精度可能存在"标签天花板" |
| 5 | 预测"提高分辨率能提 3–5 点" | 384px 实测 85.71% vs 288px 85.17%，**仅 +0.54** | 🟡 预测被证伪，如实记录 |
| 6 | "NOAA/HF 数据可用" | 实测 20:30 可用 → 00:30 与 08:00 **均不可达**（Kaggle 正常） | 🟡 必须离线缓存 |
| 7 | "3 天可交付" | 加入域适配、集成、交叉验证后 | 🟡 **实际需 8–12 天** |

## 二、修正后的目标定义

| 任务 | 原定义 | **修正后定义** |
|---|---|---|
| 珊瑚识别 | 30 类加勒比种级 | **印太珊瑚属级（约 20 属）**，在**仙本那实测** |
| 白化判断 | 3 档（健康/白化/死亡） | **保持 3 档**，但需**印太域适配** |
| 验证方式 | 同分布随机划分 | **地理隔离**：珊瑚大三角训练 → 仙本那测试 |

> 属级不是妥协：水下照片鉴定到属是**野外调查的通行标准**（Reef Check、GCRED 的底栖调查也是属/形态类群级别）。种级在自然光水下影像里常不可靠。

## 四、修正后的技术方案

### 4.1 实验设计（防泄漏，这是可信度的根基）

```
训练集：珊瑚大三角全域（-11~22°N, 92~141°E）  剔除仙本那 bbox
验证集：从训练集按「观察 ID」划分（绝不按照片切分，防同观察多图泄漏）
测试集：仙本那 bbox（4.0–4.8°N, 118.2–119.0°E）
        —— 与训练集地理完全隔离，测出的就是真实跨地点泛化精度
```

### 4.2 模型

| 环节 | 方案 | 理由 |
|---|---|---|
| 骨干初始化 | **NOAA 太平洋底栖 YOLO11m-cls** 或 ImageNet ConvNeXt | 前者特征来自印太水下域，迁移更优 |
| 类别 | **属级 ~20 类**（仙本那 ≥8 条 且 训练侧 ≥40 条） | 每一类都能训、能测 |
| 集成 | ConvNeXt-T + EfficientNet-B0 + YOLO11m-cls（3 模型 logits 平均） | 实测最稳的 +2–4 点手段 |
| 输入尺寸 | 320–384（iNat 原图普遍 ≥1000px） | 原图信息量充足 |
| 增强 | RandAugment + MixUp/CutMix + **水下色彩仿真** | 小样本 + 域漂移 |
| 损失 | Class-Balanced / Logit Adjustment | 长尾类别 |
| 推理 | 温度标定 + 拒识阈值（分任务 TTA：识别关、白化开） | 已在白化上实测有效 |

### 4.3 白化域适配

```
现有 3 类模型（91.26%）
      ↓ 在 CORAL_INDO 印尼数据（747+130）上做轻度微调
      ↓ 用 iNaturalist 仙本那照片做无监督域统计校验
域适配后的白化模型（印太可用）
```

⚠️ **诚实声明**：CORAL_INDO 的白化标签是 NOAA ViT 模型的**伪标签**，不是人工标注。因此它只能用于**域适配**，不能用于报告"在印尼数据上的精度"。

## 六、评估协议（让数字站得住）

1. **地理隔离测试**：训练集绝不包含仙本那任何照片
2. **观察级划分**：多图观察不跨 split
3. **Bootstrap 置信区间**：报 `XX.X%（95%CI a–b）` 而非裸数字
4. **分层报告**：属级 Top-1 / Top-3 / 宏 F1 / 混淆矩阵 / 每类样本量
5. **选择性预测**：覆盖率–准确率曲线 + 拒识阈值（高置信区间可达 99.9%，须同时报覆盖率）
6. **误差来源分析**：同科/同形态类群混淆（预期仍集中在 Faviidae/Merulinidae 等）
7. **许可证合规**：iNaturalist 照片全部记录 license 与作者（已实现 `ATTRIBUTION.csv`）

## 八、风险与降级

| 风险 | 概率 | 降级方案 |
|---|---|---|
| 珊瑚大三角数据下载量过大 | 中 | 每类限 400 观察（脚本已内置 `--max-per-class`） |
| iNat 图片部分失效 | 中 | 下载器跳过坏图并统计，保证每类最低数量 |
| 属级仍有长尾 | 高 | 合并低频属为「其他」，或降到形态类群（分枝/块状/叶片/桌状） |
| NOAA 骨干加载失败 | 低 | 回退 ImageNet ConvNeXt |
| 仙本那测试照片偏少 | 中 | 扩大到沙巴全境 803 条；或做 5 折交叉验证 |
| 时间不足 | 中 | 保「属级识别 + 白化」两项核心，放弃集成与交叉验证 |
