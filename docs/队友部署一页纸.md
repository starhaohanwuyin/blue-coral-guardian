# 队友部署一页纸（照着做，约 20 分钟）

> 你（队友）会拿到两样东西：① 我发的 **`delivery.zip`（516 MB）** ② GitHub 两个仓库的协作邀请。
> 下面每一步都写清了**在 Windows 上**怎么操作。遇到问题看最后的「常见坑」。

---

## 第 0 步：接受邀请（2 分钟）

打开 https://github.com/notifications → 找到邀请 → 点 **Accept**（两个仓库都要接受）：
- `blue-coral-miniprogram` ← **小程序**，必装
- `blue-coral-ml` ← **AI 算法**，要做真实识别就必装

## 第 1 步：克隆两个仓库（3 分钟）

在你想放项目的目录（例如 `D:\coral`）打开 PowerShell：

```powershell
git clone https://github.com/starhaohanwuyin/blue-coral-miniprogram.git
git clone https://github.com/starhaohanwuyin/blue-coral-ml.git
```

## 第 2 步：把交付包放进算法仓库（关键，别漏）

1. 解压我发的 `delivery.zip`（可以先核对完整性：SHA256 =
   `8FF60485A1363B8118F06D8B0CDB243895E5B35B360541A613B8C401EE31B12E`）
2. 把解压出来的 **`weights`** 和 **`data`** 两个文件夹，**覆盖到** `blue-coral-ml\` 下：

```
blue-coral-ml\
├── scripts\          （仓库自带）
├── weights\          ← 从交付包复制（约 470 MB：分割/属/白化主模型/共识第二模型/计数）
└── data\
    ├── noaa\         ← ⚠️ 必须复制！climate_index.json + site_profiles.json（只有 8 MB）
    │                    漏了它 → 小程序的环境卡片会显示"无数据"
    └── semporna_photos\  ← 可选（示例图片按钮用）
```

## 第 3 步：装依赖并启动 AI 服务（8 分钟）

```powershell
cd blue-coral-ml
pip install -r requirements.txt

# 有 NVIDIA 显卡：先按 https://pytorch.org 装 CUDA 版 torch，再执行上面的 pip
# 没显卡：直接装即可，会自动用 CPU（约 5–10 秒/张）

cd scripts
python serve_fusion.py --host 0.0.0.0 --port 8000
```

**首次启动要加载 4 个模型，等 40–90 秒**，看到 `Uvicorn running on http://0.0.0.0:8000` 就是好了。

## 第 4 步：验证服务（1 分钟）

**新开一个 PowerShell 窗口**：

```powershell
curl http://127.0.0.1:8000/health
```

应该看到（关键是这三项）：

```json
{"status":"ok","segCalibrated":true,"coralCounter":"loaded","bleachAlt":"bleaching_all_multidomain2"}
```

再验证**气候档案有没有放对**（这条能查出第 2 步的 `data/noaa` 是否漏放）：

```powershell
curl "http://127.0.0.1:8000/climate?lat=4.4&lon=118.8&year=2024"
```

应返回 `"ok":true` 与 `"baaLabel":"白化警报一级"`。

## 三种启动方式（**Windows 语法**，默认就够用）

```powershell
# ① 默认（推荐）：主模型 + 共识第二模型，实拍一致率 73%
python serve_fusion.py --host 0.0.0.0 --port 8000

# ② 面向印太海域：换用"印太专精"的第二模型（需自备该权重）
$env:CONSENSUS_ALT = 'bleaching_all_koh_tao_bb'
python serve_fusion.py --host 0.0.0.0 --port 8000

# ③ 关掉"双模型共识"提示（其它功能不受影响）
$env:DISABLE_BLEACH_CONSENSUS = '1'
python serve_fusion.py --host 0.0.0.0 --port 8000
```

> ⚠️ **不要**写 `DISABLE_BLEACH_CONSENSUS=1 python serve_fusion.py` —— 那是 Linux 写法，
> 在 Windows 的 PowerShell 和 cmd 上都会直接报错。cmd 里请写成两行：
> `set DISABLE_BLEACH_CONSENSUS=1` 回车，再运行 `python serve_fusion.py ...`

## 常见坑（我们踩过的）

| 现象 | 原因 | 解决 |
|---|---|---|
| 环境卡片显示"无数据" | 漏放 `data/noaa/` 两个 JSON | 从交付包复制 `data/noaa/` 过去 |
| 上传后测不出珊瑚 | AI 服务没启动 / 端口不是 8000 | 确认服务窗口没关、`curl /health` 有 `ok` |
| 报"网络请求失败" | 域名校验 | 开发者工具 → 详情 → 本地设置 → 勾选「不校验合法域名」 |
| 启动报 `ModuleNotFoundError` | 依赖没装全 | `pip install -r requirements.txt`（注意先装对 torch 版本）|
| `bleachAlt` 是 `not_loaded` | 没放共识第二模型权重 | 确认 `weights/bleaching_all_multidomain2/best.pt` 存在；缺了只是没有共识提示，其它功能照常 |
| 启动命令报 `不是内部或外部命令` | 用了 Linux 的 `变量=值` 写法 | 按上面「三种启动方式」的 Windows 写法 |
