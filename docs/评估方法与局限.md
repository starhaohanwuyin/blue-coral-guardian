## 二、关键实测结果

### 2.1 Cluster bootstrap：朴素 CI 确实偏乐观

| 方法 | 95% CI | 宽度 |
|---|---|---|
| 按样本 bootstrap | [84.10%, 88.24%] | 4.14 pt |
| **按观察 cluster** | **[83.33%, 88.88%]** | **5.55 pt** |

- 499 个观察簇，平均 2.18 张/观察
- **聚类 CI 宽 1.34 倍** → 同一观察的多张照片确实相关，朴素 CI 低估了方差
- **报告口径：以聚类 CI 为准**

### 2.2 McNemar 检验：新旧白化模型在印尼域的差异**高度显著**

| 项目 | 值 |
|---|---|
| 模型A（bleaching_ip） | 85.23% |
| 模型B（bleaching_new） | 21.02% |
| A对B错 (b) / A错B对 (c) | **128 / 15** |
| 精确二项 p 值 | **< 0.000001** |
| 聚类 95% CI（B−A） | [−71.88%, −55.56%]（不含 0）|

> 结论：「新模型在印尼域更差」**不是样本波动**，是统计显著的真实退化。

### 2.3 错误归因：错误集中在低置信区（拒识有效）

| 置信度区间 | 样本数 | 错误率 |
|---|---|---|
| [0.0, 0.3) | 13 | **100.0%** |
| [0.3, 0.5) | 64 | 65.6% |
| [0.5, 0.7) | 107 | 44.9% |
| [0.7, 0.9) | 148 | 17.6% |
| **[0.9, 1.0)** | **784** | **2.9%** |

**⚠️ 高置信错误 23 个（占全部错误 15.1%）** —— 这是最危险的一类，例如：
- `Pavona → Gardineroseris`（conf 0.991）
- `Glerogyra → Physogyra`（conf 0.985）
- `Hydnophora → Goniastrea`（conf 0.985）

### 2.4 混淆对集中在**生物学近缘属**（说明错误有内在原因）

| 真实 | 误判为 | 生物学关系 |
|---|---|---|
| **Porites** | **Isopora** | Isopora 曾被视为 Porites 的亚属 |
| **Plerogyra** | **Physogyra** | 同科，气泡状形态极相似 |
| **Duncanopsammia** | **Galaxea** | 同科 Dendrophylliidae |
| **Fimbriaphyllia** | **Lobophyllia** | 同科 Lobophylliidae |
| **Acropora** | **Isopora** | 同科 Acroporidae |

> 含义：这些混淆**连专家也容易出错**，属于任务固有难度，而非模型缺陷。

### 2.5 图像质量对错误的影响（弱但一致）

| 指标 | 正确样本 | 错误样本 | 差异 |
|---|---|---|---|
| 对比度 | 0.1894 | 0.1756 | −0.0138 |
| 亮度 | 0.3525 | 0.3488 | −0.0037 |
| 饱和度 | 0.1799 | 0.2060 | +0.0261 |

错误样本**对比度略低、饱和度略高**，方向与「水下劣化」一致，但差异很小。

### 2.6 产品级拒识曲线（可直接用于产品设计）

| 置信度阈值 | 自动化率 | 自动部分准确率 | 拦截的错误占比 |
|---|---|---|---|
| 0.00 | 100.0% | 86.38% | 0.0% |
| 0.50 | 93.1% | 90.66% | 36.2% |
| 0.70 | 83.5% | 94.74% | 67.8% |
| 0.80 | 78.3% | 96.11% | 77.6% |
| **0.90** | **70.3%** | **97.07%** | **84.9%** |

## 三、⚠️ 已识别的评估局限（诚实清单）

### 3.1 分割质量 mIoU ✅ **已补上（并发现重大改进点）**

**已完成**：在 Coralscapes **官方 validation split（166 张，含像素级掩膜）**上评估：

| 指标 | 512px 输入 | **1024px 输入（模型原生）** |
|---|---|---|
| **mIoU（40 类宏平均）** | 0.2529 | **0.5484** |
| 频次加权 IoU | 0.6535 | 0.6301 |
| 逐像素准确率 | 0.7897 | 0.7731 |

**按功能群 IoU（1024px，全量 166 张）：**

| 功能群 | 512px（20 张） | **1024px（166 张）** |
|---|---|---|
| 藻类覆盖 | — | **0.8678** |
| 沙/底质 | 0.6698 | **0.8006** |
| **白化珊瑚** | **0.0000** ❌ | **0.7861** ✅ |
| **活珊瑚** | **0.1435** ❌ | **0.7113** ✅ |
| 死亡珊瑚 | 0.1182 | **0.6177** |
| 其他 | 0.3070 | 0.5432 |

**⚠️ 重大发现**：
512px 下活珊瑚 IoU 仅 0.14、白化珊瑚 **完全失效（0.00）**；
改用模型原生 **1024px** 后分别升至 **0.71** 与 **0.79**。
原因是**细枝珊瑚与小面积白化斑在 512px 下被下采样抹掉**。

**产品已切换至 1024px**：
- mIoU 提升约 **117%**
- 星地验证依然成立（1024px：38.05% vs 实地 39.56%，偏差 −1.51 点，优于 512px 的 +1.29 点）
- 耗时代价：约 150ms → **600ms**（端到端 558–739ms，仍 <1 秒）

> **这是本项目最有价值的一次"评估驱动的产品改动"**：
> 如果不做 mIoU，我们永远不会发现产品用的分辨率让白化分割完全失效。

### 3.2 没有人类基线 ❌ **确认无法完成（永久局限）**

**情况**：模型属级 Top-1 = 86.12%，但**没有人类专家对照**。
**决策**：经确认**无法组织人工标注**，故此项列为**永久局限**，不列入改进计划。
**替代证据**：错误归因分析显示，模型的**混淆对集中在生物学近缘属**
（Porites↔Isopora、Plerogyra↔Physogyra、Fimbriaphyllia↔Lobophyllia、Duncanopsammia↔Galaxea），
这些连专家也容易混，说明剩余错误有相当部分来自**任务固有难度**。
**报告口径**：不宣称"达到专家水平"，只报告绝对指标并说明缺少人类对照。

### 3.3 只有「区域平均」验证，没有「站点级/逐样本」验证 ❌ **最重要**

**情况**：招牌结论是「模型 39.71% vs 实地 39.56%」——**两个平均值接近**。

**站点级拆解后（用 iNat `place_guess` 分组）**：

| 站点 | n | 模型均值 | 95% CI | 实地 LCC | 落 CI 内? |
|---|---|---|---|---|---|
| Mataking | 2 | 27.19% | [0.0, 54.3] | 26.88% | ✅ |
| **Mabul** | **11** | **44.38%** | **[23.9, 64.9]** | **22.29%** | ❌ **否** |
| Kapalai | 2 | 33.17% | [−36.3, 102.7] | 20.50% | ✅（CI 无意义）|

```
站点级偏差 +11.69 个百分点 · Pearson r = −0.563 · 排序顶端不一致
```

**根因**：
1. iNat 照片是**摄影师自选主体**（挑好看的拍），不是**等距抽样样方**
2. 站点样本量过小（2–11 张），组内标准差 20–30%，检验效力不足

**⚠️ 必须加限定**：
> **模型可用于「区域尺度」的珊瑚覆盖率估计，不足以做「站点级」优劣区分。**

**修复路径**：每站点 ≥30 张**标准化样方照片**（沿样线等距抽样），而非摄影师自选。

### 3.4 存在「测试集调参」风险 ⚠️

| 参数 | 来源 | 风险 |
|---|---|---|
| 白化类加权 **β=6** | **看着测试集结果选的** | 🔴 **测试集调参** |
| 属级置信度门槛 0.40 | 观察欠训练模型表现 | 🟡 中 |
| 对比度阈值 0.030 | 在**合成降质集**上标定 | 🟢 安全 |
| 温度 T | 在 **val** 上拟合 | 🟢 安全 |

**声明**：β=6 的工作点是在 `test_ip` 上选取的，因此该工作点的报告指标偏乐观。
**修复路径**：把测试集拆为 `test` / `test_holdout`，β 只在 `test` 上选。

### 3.5 交叉验证 ✅ **已完成**

**设计说明**：标准 K 折会轮换测试集，但我们的测试集是**地理隔离**的仙本那留出集——
轮换会让训练看到仙本那，破坏「跨域泛化」这一核心验证。
故采用 **固定测试集 + 轮换训练子集**（珊瑚大三角 34 属分层 70% 抽样，3 个种子）。

| 折 | 训练集 | 仙本那 Top-1 | 宏 F1 |
|---|---|---|---|
| 1 (seed=1) | 70% | 82.89% | 0.7947 |
| 2 (seed=2) | 70% | 82.44% | 0.8066 |
| 3 (seed=3) | 70% | 82.08% | 0.7921 |
| **均值** | | **82.47%** | |
| **标准差** | | **0.33 pt** | |
| 全量训练 | 100% | **86.12%** | |

**两个结论**：
1. **划分方差仅 ±0.33 pt** → 86.12% **不依赖特定划分**，可放心引用
2. **规模效应 +3.65 pt** → 数据量是主要瓶颈，支持继续扩充数据

> ⚠️ 注意：CV 的 82.47% 是 **70% 训练集**下的结果，不是对 86.12% 的修正；
> 报告正文的 86.12% 仍为全量训练结果。

### 3.6 类别分布 ≠ 真实使用分布 ⚠️

iNaturalist 是**公民科学**数据：好拍、好看的物种被过度采样。
报告的 Top-1 是**按测试集分布加权**，真实使用中分布不同。
**修复路径**：按真实发生频率重加权，或明确声明适用范围。

### 3.8 珊瑚个体计数（P3）✅ 已做，但真值是**自动标注** ⚠️

P3 新增的「珊瑚个体数量 + 位置」输出（YOLOv9c）是在 Coralscapes 掩膜上评估的：

| 项 | 说明 |
|---|---|
| 指标 | 官方 validation split（166 张）**mAP@0.5 = 0.4217**（验收线 0.35）|
| 泄漏隔离 | train 22 个站点 vs val 3 个站点，**不重叠**（与属级口径同源）|
| **真值口径** ⚠️ | 个体框由**语义掩膜的同类连通域**自动导出（8 邻域，≥200 px）—— **不是人工实例标注** |
| 后果 1 | 紧贴的同类个体会被合并成 1 个 → **计数系统性偏少**；mAP 是「与该自动真值的一致程度」，不能等同于人工标准下的实例检测精度 |
| 后果 2 | 阈值改变时计数会变：服务默认 `conf=0.20`（总量偏差 +2.3%）；评估脚本默认 `conf=0.25`（−27.1%）。mAP 不受阈值影响，但计数必须报工作点 |
| **跨域未验证** | 训练与验证都来自 Coralscapes（以红海为主）；**仙本那/印太真实照片未做实例级人工核验**，跨域计数准确性未知 |
| 无人类基线 | 与属级识别同样无法回答「模型达到什么水平」 |

**修复路径**：人工标注 50–100 张的**实例**标签（而非语义掩膜），
即可给出「相对人工真值」的 mAP，并把合并导致的偏少量化出来。

## 🔴 补充发现：印太域指标具有误导性（2026-10-10 审计）

**问题**：报告中「印太域准确率 82.95%」看似尚可，但**完全由类别不平衡造成**。

**证据**（`bleaching_all` 在 `test_ip` 176 张上）：

| 指标 | 值 |
|---|---|
| 总体准确率 | 0.8295 |
| **多数类基线**（无脑猜「健康」）| **0.8523** |
| **高于基线** | **−2.27 pt** ❌ |
| 白化召回 | 0.4231 |
| 健康召回 | 0.9000 |
| **平衡准确率** | **0.6615**（随机=0.5）|
| **Cohen's kappa** | **0.3231**（弱一致性）|

**成因**：`test_ip` 中健康样本占 **150/176 = 85.23%**，
而模型预测 **149/176 = 84.66%** 为健康 —— 即模型退化为「多数类预测器」。

> ⚠️ **别把两个模型混引**（2026-10-11 复核）：本节数字属于**部署模型 `bleaching_all`**。
> `reports/protocol_bleaching_ip_test_ip.json` 是**另一个模型 `bleaching_ip`**，其 `top1 = 0.852273`
> （恰等于多数类基线），bleached 召回同为 0.4231；两者差异 **McNemar p = 0.424，不显著**
> （`reports/mcnemar_bleaching_all_vs_bleaching_ip_test_ip.json`）。
> 结论不受影响：**该域不可用，且换模型也救不了**。

**对比真正有效的域**（旧域 412 张）：白化召回 0.8878、多数类基线 0.5026，
**大幅高于基线**，模型确实在判别。

**因此正确的表述是**：

> ❌ 错：「印太域准确率 82.95%」
> ✅ 对：「印太域**总体准确率低于多数类基线**（0.8295 vs 0.8523），
>        平衡准确率 0.6615、kappa 0.3231，判别能力弱；
>        该域存在严重类别不平衡，总体准确率不具参考价值。」

**决策规则能否挽救？——不能。**

| 方案 | 白化召回 | 代价 |
|---|---|---|
| A. argmax 基线 | 0.423 | — |
| B. 先验校正（修正后，用真实目标域先验）| **0.346**（反而降）| 总体准确率升至 0.886 |
| C. 阈值 β=6（极端激进）| **0.577**（上限）| 精确率降至 0.273，总体降至 0.710 |

> 阈值扫描的召回**上限只有 0.577**，说明模型对印太域白化样本的**打分排序本身就不对**，
> 这**不是决策边界问题，而是特征迁移问题**。
>
> 正确修法是**域自适应**（DANN）或**目标域微调**，需目标域标注或未标注数据。
> 详见 `方案v5-结项与后续阶段.md` 的 P1。

**连带影响**：`docs/环境数据与综合研判插件.md`、`reports/最终结果汇总.md`
等文档中凡引用「印太域 82.95%」之处，均应按上述口径修正。
