# 网页版（H5）部署指南

> 目标：**不用微信开发者工具**，用浏览器（手机或电脑）打开一个链接就能使用完整服务
> —— 上传照片 → 覆盖率 / 白化 / 珊瑚属 / 个体计数 → 环境热压力 → 投放建议 → 中英文报告。
>
> 网页版与小程序**调用同一套后端接口、同一批模型**，所以结果完全一致。

---

## 一、它是什么（30 秒看懂）

```
浏览器（手机/电脑）
      │  HTTP/HTTPS
      ▼
serve_fusion.py  （一个进程同时干两件事）
      ├── 提供网页界面：GET /            ← web/index.html + app.js + style.css
      └── 提供 AI 接口：POST /analyze、GET /climate、POST /priority …
```

**不需要 Node、不需要打包、不需要额外的 Web 服务器**：FastAPI 自己就把网页托管了。

## 二、本机用（1 分钟）

```powershell
cd D:\大学作业\广东海洋大学的珊瑚评测小程序\coral_ml\scripts
python serve_fusion.py --host 0.0.0.0 --port 8000
```

启动后浏览器打开：

| 哪个地址 | 用途 |
|---|---|
| **http://127.0.0.1:8000/** | **本机电脑浏览器**（推荐先在这验证）|
| **http://<电脑局域网IP>:8000/** | **同一 Wi-Fi 下的手机**访问 |

> 首次启动要加载 4 个模型，等 40–90 秒；看到 `Uvicorn running on http://0.0.0.0:8000` 即就绪。
> 也可双击仓库里的 `启动网页版.bat`（自动启动并打开浏览器）。

**查自己的局域网 IP**：

```powershell
Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -notlike '127.*' -and $_.IPAddress -notlike '169.254.*' } | Select IPAddress, InterfaceAlias
```

**手机连不上时**（99% 是防火墙）：以管理员身份运行一次

```powershell
New-NetFirewallRule -DisplayName "珊瑚卫士 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow
```

## 三、手机上的功能限制（**必须知道**）

浏览器有"安全上下文"限制，HTTP 与 HTTPS 能用的功能不同：

| 功能 | HTTP（局域网）| HTTPS（公网）|
|---|---|---|
| 上传相册照片 | ✅ | ✅ |
| 拍照（`capture` 唤起相机）| ✅ 多数手机可用 | ✅ |
| **定位（"用我的位置"）** | ❌ 手机浏览器禁用 | ✅ |
| 电脑端全部功能 | ✅ | ✅ |

→ 手机端要**完整功能（含定位）**，就需要 HTTPS（见第四节）。没有 HTTPS 时，用手动选点位即可，不影响识别结果。

## 四、给公网访问（一个真正的"链接"）

### 方案 A：临时公网链接（10 分钟，适合演示/临时给老师看）

用内网穿透工具把本机 8000 端口映射到公网，**自带 HTTPS**。任选其一（需能访问其官网下载）：

```powershell
# ① Cloudflare Tunnel（免费、自带 https 域名）
winget install --id Cloudflare.cloudflared
cloudflared tunnel --url http://localhost:8000
#   运行后会打印形如 https://xxxx-yyyy.trycloudflare.com 的地址，直接用

# ② 或 frp / ngrok（同理由其客户端打印公网地址）
```

> 优点：不用服务器、不用备案、立刻能用；缺点：**地址是临时的**（关掉就失效），不适合长期上线。

### 方案 B：云服务器 + 域名（正式上线，这才是"永久链接"）

**你需要的三样东西**（我无法代买，但下面配置可直接用）：
1. 一台云服务器（2 核 4GB 起；**GPU 不是必须**，CPU 推理约 5–10 秒/张；国内厂商需 ICP 备案）
2. 一个域名
3. 服务器上装好 Python 3.10+、把项目与 `weights/`、`data/` 放好（用交付包）

**B1. 在服务器上把服务跑成后台常驻（systemd）**

`/etc/systemd/system/coral.service`：

```ini
[Unit]
Description=Coral Guardian AI Service
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/opt/coral-ml/scripts
ExecStart=/usr/bin/python3 -u serve_fusion.py --host 127.0.0.1 --port 8000
Restart=always
RestartSec=5
Environment=PYTHONUNBUFFERED=1
# 若想关掉双模型共识提示，取消下面这行注释
# Environment=DISABLE_BLEACH_CONSENSUS=1

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now coral
sudo systemctl status coral        # 应看到 active (running)
curl http://127.0.0.1:8000/health  # 应返回 {"status":"ok",...}
```

**B2. Nginx 反向代理 + HTTPS（含大文件上传）**

`/etc/nginx/sites-available/coral`：

```nginx
server {
    listen 80;
    server_name coral.example.com;          # ← 换成你的域名
    client_max_body_size 20m;               # 照片上传放宽（默认 1m 会 413）
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 300s;            # CPU 推理较慢，避免超时
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/coral /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

**B3. 域名与 HTTPS 证书**

1. 域名解析：在域名商后台加一条 **A 记录** → 指向服务器公网 IP（如 `coral` → `1.2.3.4`）
2. 签证书（自动、免费、90 天自动续期）：

```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d coral.example.com     # 会自动改 nginx 配置并加上 443
```

3. 完成后访问 **https://coral.example.com** —— 手机定位、拍照全部可用 ✅

> ⚠️ **国内服务器注意**：域名解析到大陆服务器**必须先做 ICP 备案**（约 2–3 周，需主体资质）；
> 不想备案就用香港/新加坡节点，或先用方案 A 的临时链接。

## 五、与小程序的关系

| 问题 | 答案 |
|---|---|
| 网页版会不会影响小程序？ | **不会**。网页是**新增**的静态目录 + 根路径挂载，`/analyze` 等接口行为完全未变（有回归验证：23/23）|
| 两边结果一致吗？ | **完全一致**：同一个后端、同一批模型权重 |
| 小程序还需要吗？ | 需要（微信内分享、扫码即用）；网页版解决"没有微信/不想装工具也能用"|

## 六、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 打开 `http://127.0.0.1:8000/` 显示 404 | `web/` 目录丢了 | 确认 `coral_ml/web/index.html` 存在（仓库里有）|
| 手机打不开局域网地址 | 防火墙 / 不在同一 Wi-Fi | 见第二节的防火墙命令；确认手机连的是同一个路由器 |
| 页面上点"用我的位置"没反应 | HTTP 下手机浏览器禁用定位 | 用预设点位，或部署 HTTPS（第四节）|
| 上传大照片报 413（公网）| Nginx 默认限制 1 MB | 加 `client_max_body_size 20m`（见 B2）|
| 照片分析很慢（5–10 秒）| 服务器无 GPU，CPU 推理 | 正常；有 NVIDIA 显卡的机器装 CUDA 版 torch 后可到 <1 秒 |
| 环境卡片显示"无数据" | 坐标在网格外，或漏放 `data/noaa/` | 选预设点位；确认 `data/noaa/*.json` 已放好 |

---

## 七、一句话总结

- **本机 / 局域网**：`python serve_fusion.py --host 0.0.0.0 --port 8000` → 手机电脑都能开
- **要一个公网链接**：先用 Cloudflare Tunnel（10 分钟、自带 HTTPS），长期上线再上"云服务器 + 域名 + nginx + certbot"
- **手机要定位功能**：必须 HTTPS；只要识别结果，HTTP 就够
