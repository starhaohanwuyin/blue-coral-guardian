# 环境数据插件 + 综合研判插件（修复优先级与保育报告）

> 本文说明「蓝珊」如何从**一张照片**扩展到**一套保育决策支持**：
> 图像研判 → 环境数据 → 综合研判 → 保育报告 → 苗投放建议。

---

## 一、整体链路

```
水下珊瑚照片
    │
    ├─① 图像研判（Model A 分割 + Model B 分类）
    │     → 活珊瑚 / 白化 / 死亡 / 藻类覆盖率、珊瑚总覆盖、主要珊瑚属
    │
    ├─② 环境数据插件（NOAA Coral Reef Watch）
    │     → DHW 峰值、白化预警等级（BAA 0–4）、热浪天数、年度对比
    │
    └─③ 综合研判插件（融合 ① 与 ②）
          → 恢复潜力 / 修复紧迫度 / 修复优先级 / 苗投放适宜度
          → 自动生成中文保育报告
          → 给出「该不该投、投哪里、什么时候投」的行动建议
```

## 二、① 图像研判（已完成，实测指标）

| 输出 | 模型 | 实测 |
|---|---|---|
| 覆盖率（活/白化/死亡/藻类/沙砾）| Coralscapes SegFormer-B2 | mIoU **0.548** |
| 珊瑚属（34 属）| ConvNeXt-Tiny | 仙本那留出集 Top-1 **86.12%** |
| 白化状态 | ConvNeXt-Tiny | 第三方独立数据 **98.21%** |
| 拍摄条件自检 | 图像统计 | 降质集 5/5 正确 |
| **珊瑚个体数量 + 位置**（P3 附加）| YOLOv9c 单类检测 | mAP@0.5 **0.4217**（官方 val 166 张）|

**外部一致性**：仙本那 180 张照片的活珊瑚覆盖估计 **39.71%** vs
Reef Check Malaysia 2024 实地 **39.56%**（差 0.15 个百分点）。

### 2.1 珊瑚个体计数（P3 · 附加能力）

- **回答什么**：画面里有几个珊瑚个体、各在什么位置（像素框 + 置信度）
- **不回答什么**：是哪个属、什么健康状态（仍由 Model A/B 负责）；**不替换分割**
- **接口**：`POST /count`（独立调用，不跑分割/分类）；
  或 `POST /analyze` 响应里的新增字段 `coralCount`（`?count=false` 可关闭）
- **真值口径（引用时必须声明）**：个体框由 Coralscapes **像素级掩膜的同类连通域**
  自动导出（8 邻域，面积 ≥200 px），**不是人工实例标注**；紧贴的同类个体会合并 → 计数偏少
- **验收**：mAP@0.5 = **0.4217** ≥ 0.35，且分割 mIoU 未下降（0.5484 → 0.5484）
- **对既有输出的影响**：**零**。既有键的名称、类型、口径全部未变，
  证明见 `scripts/verify_serve_additive.py`（改动前后逐键比对）

## 三、② 环境数据插件

### 数据来源

- **NOAA Coral Reef Watch v3.1**，5 km 分辨率
- 通过 **PacIOOS 镜像**获取（直连 coastwatch 在国内不可达）
- 覆盖范围：**4.025–5.025°N × 118.025–119.525°E**（21 × 31 格点，0.05°）
- 覆盖年份：**2023 / 2024 / 2025**
- ⚠️ **网格外坐标会被拒绝**：返回 `ok=false` + 覆盖框 + "最近格点及其距离"，
  **不会**给出热压力结论（理由见第七节局限表：静默取最近格点会产生跨千公里的错误结论）

### 关键指标

| 指标 | 含义 |
|---|---|
| **DHW**（Degree Heating Weeks）| 累积热压力，单位 °C·周。NOAA 标准：≥4 显著白化，≥8 常伴死亡 |
| **BAA**（Bleaching Alert Area）| 0 无压力 / 1 白化观察 / 2 白化警告 / 3 警报一级 / 4 警报二级 |

**BAA 与 DHW 的真实对应关系**（从 NOAA 数据实测校准，**非**直觉假设）：

| BAA | 名称 | 触发条件 |
|---|---|---|
| 0 | 无压力 | DHW = 0 |
| 1 | 白化观察 | HotSpot ≥ 1，DHW 仍为 0 |
| 2 | 白化警告 | **DHW > 0** |
| 3 | 警报一级 | **DHW ≥ 4** |
| 4 | 警报二级 | **DHW ≥ 8** |

> ⚠️ **踩坑记录**：本项目最初按「BAA3 = DHW≥8、BAA4 = DHW≥12」自行推算，
> **整整高估了一档**（仙本那 2024 核心区官方为 BAA 3，推算只得到 2）。
> 现已改为**直接使用 NOAA 官方 CRW_BAA 产品**，仅在无官方值时才用已校准的阈值兜底。
| 热浪天数 | DHW≥4 与 DHW≥8 的天数 |
| 年度对比 | 与其它年份的偏高幅度 |

### 实测结果（仙本那核心区 4.2–4.6°N, 118.6–119.0°E，64 格点）

| 年份 | 区域最大 DHW | 核心区最大 DHW | 核心区平均 | DHW≥8 天数 | 等级 |
|---|---|---|---|---|---|
| 2023 | 6.31 | 3.78 | 2.19 | 0 | 白化观察 |
| **2024** | **14.87** | **10.03** | **4.88** | **51** | **白化警报二级** |
| 2025 | 6.76 | 4.03 | 2.76 | 0 | 白化观察 |

> **2024 年是一次重大白化事件**：核心区最大 DHW 比常年高 **148%**，
> 且出现 51 天 DHW≥8（严重热应激）。

**⚠️ 口径说明**：14.87 是**网格区域最大**（出现在 4.225°N, 118.025°E，即网格西缘）；
仙本那**核心区**的实测峰值是 **10.03**。引用时须区分，不可混用。

### 接口

```
GET /climate?lat=4.4&lon=118.8&year=2024
GET /climate/cells?limit=200
GET /climate/profile?lat=4.4&lon=118.8      # 投放时间窗档案（见下）
```

### ①b 投放窗口与热压力档案（往年白化预警记录 → 建议避开月份）

**回答的问题**：这片海**往年哪个时间段白化预警严重**？**哪些格点多年比较稳**？
→ 给出「建议避开哪几个月投放 / 哪些格点在热压力维度上更友好」的**规则化建议**。

| 项 | 说明 |
|---|---|
| 数据 | 本地已缓存的 NOAA CRW 日数据（DHW / BAA / HotSpot × 2023–2025），**不联网、不用 GPU** |
| 生成 | `python scripts/climate_site_profile.py --build`（约 3 分钟）→ `data/noaa/site_profiles.json` + `reports/deployment_windows.json` |
| 查询 | `GET /climate/profile?lat=&lon=`；`/analyze` 带 lat/lon 时也会新增 `deployment` 字段 |
| 判定 | **年年达警戒**（3 年都 DHW≥4）→ 不建议投放；**部分年份** → 避开风险月；**3 年均未达** → 热压力维度友好 |
| 风险月口径 | **DHW≥4 ∪ HotSpot≥1** 取并集（DHW 是 12 周累积量、会滞后，HotSpot 把预警窗口提前覆盖）|
| 实测分布 | 544 个格点：**32 个年年达警戒** / 254 个部分年份 / **258 个三年均未达警戒**；风险集中在 **5–8 月**（6 月最重）|

> ⚠️ **四条必须随结论一起讲的口径**（响应里 `caveats` 也带）：
> ①**只有热压力这一个维度** —— 底质/水深/水流/藻类/草食动物/人力管护都不在模型里；
> ②**样本仅 3 年**，2024 是极端年，"多年稳定"≈"只遇上一次事件"，不等于以后不会遇上；
> ③**5km 格点 ≠ 礁点**，能说"哪片海"，不能说"哪个礁"；
> ④**这不是投放效果评估** —— 项目**没有投放后的存活率数据**，因此"效果比较好"不能写。
>
> 另外档案里带**空间自检告警**：西缘（≤118.2°E）3 年最高 DHW 均值 12.79，是中部（5.44）的 2.4 倍，
> 呈平滑东西梯度，更像**近岸浅水/陆缘像元效应**而非礁块差异 —— **不要仅凭格点数值就排除一个真实礁点**。

## 四、③ 综合研判插件

### 4.1 设计定位（重要）

> **这是基于规则的决策支持启发式（rule-based decision support heuristic），
> 不是经过验证的预测模型。**

- 评分维度与权重来自 **NOAA CRW 公开标准**与珊瑚礁修复文献的通行做法
- 但「哪个点位该优先修复」是**价值判断**，**不存在客观 ground truth**
- 因此本项目 **不报告任何"准确率"**，只报告评分构成与依据
- 用途：为人工决策**提供排序参考与理由**，不替代专业评估

### 4.2 三个评分

**① 恢复潜力（Recovery Potential，0–100）** —— 这片海域能否恢复、苗能否存活

| 维度 | 权重 | 依据 |
|---|---|---|
| 活珊瑚存量 | 30% | 恢复的种源；参考满值 0.40（= RCM 区域平均 39.56%）|
| 结构完整性 | 20% | 低死亡 → 礁体框架还在 |
| 藻类竞争低 | 20% | 藻类少 → 幼体有附着空间 |
| 属多样性 | 15% | 属越多抗逆性越强；参考满值 8 属 |
| 低热应激 | 15% | 未来不反复白化 |

**② 修复紧迫度（Urgency，0–100）** —— 现在需不需要干预

| 维度 | 权重 |
|---|---|
| 白化程度（占珊瑚总量）| 40% |
| 死亡率 | 30% |
| 热应激等级 | 30% |

**③ 修复优先级（Priority）**

```
priority = 0.55 × 恢复潜力 + 0.45 × 紧迫度
```

> 恢复潜力权重更高，对应需求「**优先选择恢复潜力高的海域**」。

**④ 苗投放适宜度**

```
seedling = 恢复潜力 × (0.6 + 0.4 × 紧迫度/100)
```
既要「能活」（恢复潜力），也要「需要」（紧迫度）。

### 4.3 数据质量闸门

拍摄条件为 `poor` 时，优先级**封顶 50 分**并附警告 —— 拍得差就不给高结论。

### 4.4 约束优先的建议逻辑

建议按**真正的瓶颈**排序，先回答「能不能投」：

```
若 热压力高 且 场地差  → 双重不利，暂缓
若 仅 热压力高         → 苗圃暂养 / 等热浪过后
若 仅 场地差           → 先做环境改良（清藻、补基质）
若 两者都可行          → 按优先级给出：最优先 / 建议投放 / 备选 / 暂缓
```

### 4.5 实测行为（5 个场景）

| 场景 | 恢复潜力 | 紧迫度 | 优先级 | 首要建议 |
|---|---|---|---|---|
| 健康礁区（2025）| 80.4 | 22.7 | 54.4 三级 | 保育备选区 |
| 受损+有潜力（2025）| 67.1 | 56.5 | **62.3 二级** | **建议投放区** |
| 白化事件中（2024）| 50.0 | 70.0 | 59.0 三级 | **建议苗圃暂养** |
| 严重退化（藻类主导）| 17.6 | 63.3 | **38.2 四级** | **先做环境改良** |
| 拍摄质量差 | 67.1 | 56.5 | 50.0（封顶）| 保育备选 + 降级警告 |

**同一片礁区、不同年份**的对比体现了环境数据的作用：

| 年份 | 气候 | 首要建议 |
|---|---|---|
| 2024 | 白化警告 | **建议苗圃暂养**（热浪期不宜投放）|
| 2025 | 白化观察 | **建议投放区**，可常规规模投放 |

### 4.6 接口

```
POST /analyze          （带 lat/lon/year 表单字段或查询参数，自动附带研判）
POST /priority         （独立调用，只需覆盖率数字 + 坐标）
```

## 七、局限

| 局限 | 说明 |
|---|---|
| **无 ground truth** | 修复优先级无客观标准答案，故不报准确率 |
| **权重未经标定** | 权重取自文献通行做法，未用真实修复成效数据优化 |
| **单点代表整片** | 一张照片代表一个点位，未做空间插值 |
| **气候数据年际稀疏** | 仅 2023–2025 三年（**不是实时/临近预报**），无法做长期趋势，也不能回答"现在热压力多少" |
| **BAA 来源（已更正）** | ✅ **优先取 NOAA 官方 CRW_BAA 产品**（响应里 `baaSource` 会标明）；仅在官方值缺失时按**已校准**阈值兜底并标 `baaEstimated=true`。⚠️ 本表旧版本误写为"由 DHW 阈值推算"，与代码不符 |
| **空间覆盖有限，网格外直接拒绝** | 仅 **4.025–5.025°N × 118.025–119.525°E**。网格外返回 `ok=false` 并给出覆盖框与最近格点距离；**绝不**用"最近格点"代替 —— 早期实现会静默取最近格点，实测查深圳（约 2000 km 外）会返回"仙本那的 DHW 9.65 / 白化警报二级 / 严重热应激"这种**错误结论** |
| **站点级不可用** | 卫星 5km 格点 ≠ 站点点位：**事件级**一致（2024 大范围白化），**站点级**不一致（n=4，仅供方向参考）|
| **"DHW 峰值"必须标空间单位** | 同一片海有三个数：**查询格点 5.42** / 仙本那核心区 **10.03** / 网格最大 **14.87**。引用时必须说清是哪一个 |
| **计数真值为自动标注**（P3）| 个体框来自掩膜连通域，紧贴个体合并 → 偏少；跨域实拍照片未做实例级人工核验 |
| **无社会经济因子** | 未考虑可达性、成本、社区意愿等真实决策要素 |
