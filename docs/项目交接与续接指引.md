### 4.3 **语法检查不要用退出码猜**

PowerShell 下 `node --check x.js` 的 `$LASTEXITCODE` 会误判。正确方式：
```powershell
$p = Start-Process node -ArgumentList "--check","x.js" -NoNewWindow -Wait -PassThru `
     -RedirectStandardError "$env:TEMP\e.txt" -RedirectStandardOutput "$env:TEMP\o.txt"
if($p.ExitCode -eq 0){ "OK" } else { Get-Content "$env:TEMP\e.txt" }
```
Python 侧用 `python -c "import ast; ast.parse(open('x.py',encoding='utf-8').read())"`。

```python
#   ① 取珊瑚类（非 substrate/algae/background/class_0）
#   ② 提连通域：scipy.ndimage.label 或 cv2.connectedComponents
#      ✅ 实测 scipy 与 cv2 **均已安装**，两种都可用
#   ③ 过滤极小连通域（< 200 px）
#   ④ 每域取 bounding box → YOLO 格式：class cx cy w h（归一化）
```

**依赖实测（已验证）**：`scipy` ✅、`cv2` ✅、`ultralytics` ✅、`pyarrow` ✅

```

├── images/{train,val}/
```

### 4) 训练

**8GB 显存 → batch 不要超过 8，imgsz 640。**

### 5) 评估与验收
验收标准：**mAP@0.5 ≥ 0.35**，**且现有分割指标不下降**（跑 `eval_segmentation_miou.py` 对比）。

# §8 踩坑词典（**已修过的 20+ bug，别重犯**）

## 8.1 会造成**错误结论**的（最危险）

| # | 问题 | 教训 |
|---|---|---|
| 1 | 评估代码**类别索引重映射错位** → 假报 6.25%（实为 85.23%）| 用 `ImageFolder` 加载子集时**索引会重排**，必须显式 remap |
| 2 | **类别名大小写写死**（`== "bleached"` vs 模型返回 `"Bleached"`）→ 召回**恒为 0%**且**不报错** | 一律 `.lower()` 比较 |
| 3 | **BAA 用 DHW 阈值推算，阈值整整高估一档** | **能拿官方产品就别推算**；推算必须先验证 |
| 4 | **512px mIoU 只测 20 张** → 得出"白化完全失效(0.00)"的错觉（全量实为 0.3475）| 子集结论必须回到全量复核 |
| 5 | 自蒸馏 KL 损失放大 30 万倍（用 `batchmean` 而非逐像素）| 损失尺度要 sanity check |
| 6 | 缺锚定损失 → 退化漂移（L0 从 39.66% 崩到 75.73%）| 自蒸馏必须锚定 |
| 7 | **印太域 82.95% 具误导性**（多数类基线 85.23%）| **不平衡数据必须报基线 + 平衡准确率 + kappa** |
| 8 | 主指标用聚类 CI、曲线用朴素 CI | **同一份报告口径必须统一** |
