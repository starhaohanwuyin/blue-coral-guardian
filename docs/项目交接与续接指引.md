## 四、P1 已完成的内容（避免重复劳动）

### 4.1 修掉的 bug

`scripts/eval_decision_rules.py` 的**先验校正实现错误**：
原代码 `probs / prior^τ` 只除**训练先验**，
而 `bleached` 与 `healthy` 的训练先验都是 0.375 → **等于没除** → 先验校正"完全无效"。

已改为联合目标域先验：`p'(y|x) ∝ p(y|x)/p_train(y)^τ × p_target(y)^τ`
并新增 `--target-prior` 参数。

### 4.2 关键发现（**已写入文档，勿重复报告**）

**印太域（`test_ip`，176 张）指标具误导性**：

| 指标 | 值 |
|---|---|
| 总体准确率 | 0.8295 |
| **多数类基线** | **0.8523** |
| **高于基线** | **−2.27 pt** ❌ |
| 平衡准确率 | 0.6615 |
| Cohen's kappa | 0.3231 |

模型预测 149/176 = 84.66% 为「健康」，真实健康 85.23% → **退化为多数类预测器**。

**结论**：决策规则**无法挽救**（阈值扫描召回上限仅 0.577）。
这是**特征迁移问题**，需域自适应（DANN）或目标域微调。

**已同步修正的文档**：`评估方法与局限.md`、`阶段成果与发现汇总.md`、
`scripts/make_report.py`（新增多数类基线对照表）。
