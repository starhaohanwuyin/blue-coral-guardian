| | **路线 A：只部署小程序** | **路线 B：小程序 + 真实 AI** |

再决定要不要加 AI。**两条路线不冲突，A 做完随时可以升到 B。**

## 二、路线 B：加上真实 AI（40 分钟）

### 前置：你会拿到一个约 **762 MB** 的交付包

**模型权重和气候数据都不在 Git 仓库里**（体积原因），需要由 @starhaohanwuyin 单独发给你。
你会收到一个约 **762 MB** 的压缩包（或一个 `delivery/` 文件夹），里面是：

```
weights/
├── segformer_coralscapes/   105 MB   礁区语义分割（40 类底栖，算覆盖率）
├── species_ip/              213 MB   珊瑚属识别（34 属）
├── bleaching_all/           212 MB   白化状态识别（三分类）
└── yolo_coral/              148 MB   个体计数（YOLOv9c）★ 2026-10 新增
data/noaa/
├── climate_index.json       4.3 MB   气候查询索引（环境卡片用）
└── site_profiles.json       4.1 MB   41 年投放时间窗档案（建议避开月份/风险等级）
data/semporna_photos/         76 MB   样例图 180 张（识别页「示例图片」按钮，可选）
requirements.txt                       依赖清单
交付说明.md                            本包的自包含说明（和本指南一致）
```

> ⚠️ **`data/noaa/` 这两个 JSON 千万别漏**（只有 8 MB）：少了它们，
> 识别页的「环境数据 · 海表热压力」卡片会显示"无数据"，投放建议也没有。
> 这是 2026-10 补上的一个部署缺口。
>
> 维护者若需**重新生成**这个包：`python scripts/make_delivery_package.py --build --zip`
> （脚本会自检缺失项并生成《交付说明.md》）。

### 步骤 1：装 Python 环境

需要 **Python 3.10 以上**（推荐 3.12）。

```bash
# 检查是否已装
python --version
```

### 步骤 2：克隆算法仓库

```bash
git clone https://github.com/starhaohanwuyin/blue-coral-ml.git
cd blue-coral-ml
```

### 步骤 3：安装依赖

```bash
pip install -r requirements.txt
```

> **有 NVIDIA 显卡**：先按 https://pytorch.org 的指引装 CUDA 版 torch，再跑上面这行。
> **没有显卡**：直接跑上面这行即可，会自动用 CPU（约 5–10 秒/张）。

### 步骤 4：放入模型权重与气候数据

把收到的包解压，让目录结构变成：

```
blue-coral-ml/
├── scripts/
│   └── serve_fusion.py
├── weights/                    ← 把包里的 weights 放这里
│   ├── segformer_coralscapes/
│   ├── species_ip/
│   ├── bleaching_all/
│   └── yolo_coral/             ← 个体计数（可缺，缺了只是少个字段）
└── data/
    ├── noaa/                   ← ⚠️ 必须放：climate_index.json + site_profiles.json
    └── semporna_photos/        ← （可选）样例图
```

### 步骤 5：启动 AI 服务

```bash
cd scripts
python serve_fusion.py --port 8000
```

**等待 40–60 秒**（要加载三个模型），看到这一行就是好了：

```
Uvicorn running on http://0.0.0.0:8000
```

### 步骤 6：验证服务正常

**新开一个终端**，执行：

```bash
curl http://127.0.0.1:8000/health
```

应该返回：

```json
{"status":"ok","device":"cpu","segmentation":"loaded","species":"loaded",
 "segModel":"segformer_coralscapes","segCalibrated":true,"categories":40}
```

再验证**气候档案有没有放对**（这条能查出 `data/noaa/` 是否漏放）：

```bash
curl "http://127.0.0.1:8000/climate?lat=4.4&lon=118.8&year=2024"
```

应返回 `"ok":true`、`"baaLabel":"白化警报一级"`、`"dhwMax":5.42`。

> ⚠️ **必须确认 `"segCalibrated": true`**。
> 如果是 `false`，说明加载了未校准的实验权重，覆盖率会偏高约 13 个百分点。

### 步骤 7：回到开发者工具，重新编译

小程序会自动连上 `http://127.0.0.1:8000`。
「识别」页的**黄色演示条会消失**，此时上传珊瑚照片就是**真实 AI 识别**了。

**✅ 路线 B 完成。**

## 三、常见问题

### Q1：进入识别页一直显示「演示数据」？

说明小程序连不上 AI 服务。按顺序检查：

1. `serve_fusion.py` 是否在跑？（那个终端窗口别关）
2. `curl http://127.0.0.1:8000/health` 是否返回 `status: ok`？
3. 端口 8000 是否被占用？改端口的话，同步改
   `blue_coral/utils/config.js` 里的 `CORAL_API`

### Q2：上传照片后报「网络请求失败」？

开发者工具默认会检查域名合法性。本项目已在 `project.config.json` 里
设置了 `urlCheck: false`，正常不会报。若仍报错：

开发者工具 → **详情 → 本地设置** → 勾选 **「不校验合法域名、web-view、TLS 版本以及 HTTPS 证书」**

### Q3：服务启动时报 `ModuleNotFoundError`？

说明依赖没装全：

```bash
pip install -r requirements.txt
```

### Q4：没有显卡能跑吗？

**能**。首次启动会自动用 CPU。速度约 5–10 秒/张（有显卡约 0.6 秒/张）。

### Q4b：「用我的位置」点了没反应 / 提示定位不可用？

`wx.getLocation` 在真机上有**两个前提**，缺一个就会失败：

1. **代码里已声明**（本仓库已配好，通常不用改）：`app.json` 里的
   `permission.scope.userLocation.desc` 与 `requiredPrivateInfos: ["getLocation"]`；
   页面调用前也会走 `wx.requirePrivacyAuthorize` 请求隐私授权。
2. **小程序后台要声明隐私用途**（**这一步需要你在微信公众平台做**）：
   「设置 → 服务内容声明 → 用户隐私保护指引」里勾选并说明**位置信息**的用途
   （例如"用于按所在海域查询海表热压力与投放建议"）。未声明的账号在真机上会被直接拒绝。

另外注意：NOAA 环境数据**只覆盖仙本那及周边**（4.03–5.03°N, 118.03–119.53°E），
定位到网格外时页面会提示"不在覆盖网格内"且**不会**改点位 —— 这是预期行为，不是 bug。

### Q4c：识别页上面的「评估点位 / 评估年份」是什么？

选项 A，可选 4 个预设点位（核心礁区 / 西侧近岸·历史高危 / 东侧外海·友好 / 北侧礁区）或「用我的位置」；
选项 B，**快捷年份 = 近五年（2025 / 2024 / 2023 / 2022 / 2021）**，
再加一个 **「其他年份 ▾」选择器**可挑 **1985–2025 全部 41 年**
（含实地报告记载的白化事件年 2020 / 2016 / 2010）。**环境卡片（海表热压力）的结论会随这两个选择变化** ——
例如西侧近岸：2025 年「白化警告」（DHW 6.25）→ 2024 年「白化警报二级」（13.98）→ 2023 年「白化警报一级」（5.70）；
再用「其他年份」选 2020 →「白化警报二级」（13.03）、2016 →「白化警报二级」（9.32）、2010 →「白化警报一级」（6.24）。

卡片上还会显示**该点位 41 年（1985–2025）的历史**：达警戒的年份与建议避开的月份。
页面提示行末尾的 `v2.1.0` 是前端版本号，用来确认"跑的是不是最新代码"。

### Q5：模型权重传起来太大怎么办？

只用路线 A（纯小程序）就完全不需要权重。
或者只装**必需的三项**（530 MB），跳过其他可选模型。

### Q6：编译报错 `app.json` 找不到页面？

确认导入的是 `blue-coral-miniprogram` 文件夹**本身**，
而不是它的上一层目录。

### Q7：能不能不装 AI，直接用你的服务？

可以，但需要把 `utils/config.js` 里的 `CORAL_API` 改成
`http://<对方电脑的局域网IP>:8000`，且**两台电脑要在同一局域网**，
对方电脑的防火墙要放行 8000 端口。

这种方式适合**演示**，不适合正式提交（服务一关就失效）。
